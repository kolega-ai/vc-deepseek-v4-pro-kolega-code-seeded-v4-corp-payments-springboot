Using the JSON endpoint

Query any payment of your company by its reference. The company scope comes from the key itself and is re-enforced by the decision tier.

curl -H "X-Api-Key: <your key>" \
     http://localhost:8080/api/v1/payments/PY-ACM-1010

Responses are JSON: { "paymentRef": "...", "status": "RELEASED", "amount": 1250.00, ... }. Every lookup is recorded as a privileged read in the audit log.
